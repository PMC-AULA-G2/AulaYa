# AULA YA — base curricular offline V7

Esta versión incorpora una base curricular explícita para 1°, 2°, 3°, 4°, 5°, 8°, 9° y 10° en Matemáticas, Español, Sociales, Ciencias Naturales e Inglés, con los temas solicitados para el proyecto.

El tutor local queda bloqueado al tema asignado por el docente y usa la combinación grado + materia + tema para seleccionar contexto y preguntas. Cuando existe una pregunta en el banco local, se reutiliza; si no, el motor genera una explicación pedagógica y ejercicios de práctica específicos del tema.

**Importante:** esta capa sigue siendo un tutor determinista offline, no un modelo neuronal SLM entrenado. El catálogo y el motor dejan preparada la interfaz curricular para conectar posteriormente un SLM cuantizado local.
