# AULA YA — Microlecciones V2

Cada tema del catálogo curricular tiene una microlección vertical 9:16 generada a partir de:

**grado + materia + tema + banco de 3 preguntas**.

## Estructura
1. Hook: presenta el tema.
2. Objetivo: qué podrá hacer el estudiante.
3. Explicación: definición concreta y apropiada al grado.
4. Ejemplo guiado: caso específico, no una frase genérica.
5. Paso a paso: cómo reconocer/aplicar el concepto.
6. Error frecuente: qué no debe hacer el estudiante.
7. Reto: una de las 3 preguntas exactas del tema.

Duración aproximada: 35 segundos (5 segundos por escena).

## Regla de contenido
Nunca se mezcla un tema con otro. El contenido se resuelve con la clave:
`grado + materia + tema`.

Para cada tema se intentan recuperar las 3 preguntas del banco oficial de AULA YA. El reto usa una de ellas; los ejercicios posteriores utilizan las mismas 3 preguntas exactas.

## Calidad pedagógica
- 1.º–5.º: vocabulario concreto, ejemplos cotidianos y pasos cortos.
- 8.º–10.º: vocabulario disciplinar, relaciones causa/efecto, procedimiento y comprobación.
- Matemáticas: incluye procedimiento, unidades y comprobación cuando aplica.
- Ciencias: fenómeno → elementos → relación → evidencia.
- Sociales: contexto → causas → hechos → consecuencias.
- Español: concepto → función en un texto/oración → ejemplo → comprobación.
- Inglés: uso → estructura → oración contextualizada.

## Importante
El motor actual genera microlecciones offline y no afirma que exista un modelo generativo de vídeo ejecutándose en el dispositivo. Para producir MP4 generados por un modelo de vídeo externo se necesita un pipeline de generación/licencias y luego descargar los archivos permitidos para caché offline.
